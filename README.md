# Curriculum Vitae - Diez Florencia

## Descripción
Este trabajo práctico consiste en la realización de un Curriculum Vitae en HTML5 y CSS3.
El proyecto integra etiquetas semánticas, estilos externos y la propiedad Flexbox
para lograr una diagramación responsive y organizada.

## Trabajo realizado
Se desarrolló una página web de una sola hoja que incluye:
- Encabezado con nombre, título y navegación
- Sección "Sobre mí" con foto de perfil y descripción personal
- Sección "Experiencia Laboral" con galería de imágenes
- Sección "Datos Académicos" con panel de habilidades
- Sección "Pasión por la Fotografía" con galería experimental
- Footer con iconos de redes sociales

## Tecnologías utilizadas
- HTML5 con etiquetas semánticas (header, main, section, article, footer, figure)
- CSS3 con archivo externo vinculado
- Flexbox para la diagramación de secciones
- Fuentes tipográficas personalizadas (@font-face)
